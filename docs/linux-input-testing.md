# Linux 输入验收清单 / Linux input verification

## 范围

- Linux 仅作被控端（Client / `receive`）；X11 使用 XTEST，Wayland 使用用户授权的 RemoteDesktop Portal + EIS。
- Portal 后端须提供 RemoteDesktop v2 的 `ConnectToEIS`、键盘和指针设备，以及同一会话的 ScreenCast 物理显示器选择。
- 保留现有配对和传输协议。测试不需要 root、`uinput` 规则、XWayland 回退或修改桌面配置。

## 自动化（不访问真实桌面）

在具备项目 Rust/Tauri Linux 开发依赖的环境执行：

```sh
cargo check --locked --manifest-path src-tauri/Cargo.toml --lib
cargo test --locked --manifest-path src-tauri/Cargo.toml --lib
```

新增的 Linux 后端测试使用内存状态与 `UnixStream::pair()` 模拟 EIS 服务端，不连接桌面 D-Bus，不弹出授权框，不注入真实输入。测试覆盖：

- Wayland 检测（即使同时存在 XWayland 的 `DISPLAY`），保留 X11 键码与滚轮方向。
- 等待授权／设备时不就绪，停止或失败后不能被迟到事件重新激活。
- 常驻工作线程：一次会话结束后，缓存 D-Bus 连接所依赖的后台 I/O 任务仍可运行。
- 实际 EIS 协议的按下／释放、重复按下去重、拖动、滚轮、设备帧与单调时钟时间戳。
- 控制端切换及旧连接的迟到断线通知，不释放新连接的按键。
- 队列溢出、停止、权限撤销、设备暂停／移除时的清理；不向已撤销的设备继续发送输入。
- 暂停期间不接收／缓存输入；原设备恢复后重新开始 emulation，不重放旧按键；首次设备准备超时不影响已授权会话的暂停／键盘重建等待，但仍适用于从未就绪的首次设备设置。
- 纯键盘设备直接移除或暂停后移除时，等待同一授权连接及 seat 上的新键盘恢复；仅添加但未恢复、其他 seat 的键盘，或仍有原指针暂停时不能就绪。新键盘不继承旧按键，存活指针上的按住状态被释放，指针映射重新校验。
- 新键盘先于旧键盘移除而恢复的交错顺序同样清空输入队列（包括鼠标合并预读的按键），只接受恢复后的新命令。指针／混合设备移除仍失败关闭；停止、撤权或 EIS 断连不会被迟到的键盘恢复重新激活。
- 按映射 ID／唯一几何匹配多屏，处理负坐标、HiDPI 和边界；拒绝部分选择、镜像／重叠、重复／冲突 ID 和不明确映射。
- Wayland 保持逻辑像素，X11 保持物理像素；缩放舍入不会越过所选显示器边界。
- 普通鼠标移动与拖动按 8 ms（长期上限约 125 Hz）节拍限流，允许 0.5 ms 回调抖动，不等待凑帧或增加输入缓冲。覆盖 7.7/8.3 ms 交替回调、7.999 ms 连续回调、1 kHz 高频输入和不规则回调；不能因阈值抖动反复跳过一半事件，也不能积累补发额度。空闲、强制位置发送和重置后重新建立节拍。
- 高频输入使用缓存的本机 peer ID，不为每包创建路由探测 socket 或构造完整 `LanPeer`。缓存保留原有 host/IP 标识规则，由现有发现心跳／状态快照刷新；覆盖初始化、重复读取及 IP 变化后的刷新。不缓存或跳过配对、密钥、目标设备及 Wayland 就绪校验。
- Wayland 仅合并已经积压、同一连接的连续普通位移，不等待凑批；点击、按键、滚轮、拖动、释放和断开均为顺序边界。每批最多检查 64 条位移，随后重新检查停止／撤权／EIS 事件。
- 模拟工作线程将 64 条连续普通位移合并成最后一个坐标的一帧，后续按键仍按顺序注入；暂停会连同预读的按键一起丢弃，停止／撤权也不会执行预读输入。

这些测试和编译检查**不能替代真实合成器验收**，也不代表安装包已构建。

## 真实桌面交互验收（需本机操作者同意并在场）

先保存正在编辑的内容，准备无敏感信息的测试窗口，以及随时可操作的本机键鼠。记录桌面／合成器、Portal 前后端版本、显示器布局和缩放。使用已配对的可信控制端。

1. **首次授权**：以普通用户启动 Wayland 客户端。等待期间状态不应为 ready，控制端不能跨屏输入。允许键鼠控制并选择全部物理显示器后，确认就绪和诊断路由 `wayland-portal-eis`。
2. **拒绝／取消**：取消系统对话框，确认输入不可用并显示原因；反复打开诊断、等待发现轮询、发送网络输入包，都不能再次弹框。只有重新启动共享才重试。
3. **输入效果**：在测试窗口验证鼠标绝对定位、三键单击与拖动、双向滚轮、普通字符、左右修饰键、组合键、方向／功能／小键盘按键及长按重复。不要用破坏性快捷键测试。
4. **多屏与缩放**：分别验证单屏、多屏、负原点、100%／150%／200% 和混合缩放；在各屏四角、跨屏边缘和拖动时检查位置。只选部分屏幕、镜像布局或映射不明确时应拒绝就绪，不点击错误屏幕。
5. **停止与重启**：保持修饰键或拖动时在客户端停止共享，确认无粘键。快速停止／启动多次，不能残留多个授权窗口或由旧会话恢复 ready；第二次及后续授权仍应正常工作。
6. **控制端断线**：长按修饰键或拖动时关闭控制端或断网，等待 QUIC 断线检测（空闲超时约 10 秒），确认输入释放。用新连接恢复后，旧连接的关闭不能干扰新连接。
7. **撤销与桌面生命周期**：通过桌面的共享指示器撤销权限，确认立刻失去就绪状态且无残留输入，只能手动停止／启动重新授权。若桌面仅暂时暂停 EIS 设备（例如某些桌面的锁屏／解锁），应显示等待恢复、不缓存输入；在本机正常解锁且桌面恢复原设备后，可在原授权内恢复，但不重放旧按键／拖动，也不因超过首次 10 秒准备期限而关闭会话。暂停中停止共享／撤权仍应立即生效。纯键盘移除／重建见第 12 项；桌面若结束授权会话、断开 EIS 或移除指针／混合设备，必须失败关闭，不能自动重授权，也不绕过锁屏限制。
8. **显示器变化**：授权后更改显示器布局／分辨率／缩放／旋转，确认旧设备映射不再被盲目使用。原生显示器信息目前在应用启动时检测，因此应重启 MyKVM 后重新授权和验证。
9. **缺少后端功能**：在不支持 `ConnectToEIS` 的环境中确认明确报错，不要求提权或修改系统权限；仅在已有可用 X11 会话时，才可自行选择 X11 作为替代。
10. **X11 回归**：在真实 X11 桌面中检查 `x11-xtest` 路由、移动／点击／键盘／滚轮及断线释放，且不出现 Wayland 授权框。
11. **流畅度**：记录两端实际构建日期／源码版本（包版本号相同不代表代码已更新），用相同网络与显示器刷新率，对比持续移动、快速移动后立即停止、小幅慢移、拖窗、移动后立即单击和跨屏。可先仅更新 Ubuntu，确认接收路径优化没有影响点击／拖动；**125 Hz 节拍和回调抖动修复必须用本次代码构建并更新 Mac 控制端才会生效**。记录实际体感和卡顿是否周期性出现，条件允许时对比有线网络；ping 仅作网络参考，不把它或模拟节拍／队列测试当作跨机输入延迟实测。

12. **键盘重建**：保存工作后，由本机操作者锁屏并正常解锁；也可在本机已有键盘布局／输入源之间切换，记录桌面实际发送的设备事件。若只移除并重建纯键盘、原授权仍有效，应短暂等待后恢复，不弹新授权框、不重放原先按住的修饰键／拖动，也不继续向旧键盘发事件。等待时停止共享／撤权应立即生效。若没有替换设备，手动停止／启动共享重试；真正注销登录后原授权结束，需重新启动和授权，不能当成同一会话恢复。自动化测试只模拟事件顺序，不能证明本机或所有桌面一定会保留授权并重建键盘。

发生问题时保留 `Wayland EIS device added/resumed/paused/removed`、`Wayland EIS keyboard removed`、`Wayland EIS replacement keyboard resumed` 日志及 `Wayland input suspended/ready` 状态日志；这些记录只包含设备生命周期信息，不记录按键或鼠标输入内容。请区分暂停、纯键盘重建与会话失效，而不是只按错误出现前的运行时长推断原因。

记录各环境的通过／失败和状态／诊断详情；未完成以上交互步骤前，不应将功能描述为已通过真实桌面或所有 GNOME/KDE 版本验证。
